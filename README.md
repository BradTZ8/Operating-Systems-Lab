## Usage

    git clone https://github.com/BradTZ8/Operating-Systems-Lab
    cd REPO
    pip install notebook
    jupyter notebook OS_Laboratory.ipynb

Many cells use `%%bash`, so run it on Linux (or WSL / a Linux VM).
Keep the image files in the same folder as the notebook.
